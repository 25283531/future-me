记忆演变 · 设置

记忆系统是拟人化、会自己演变的：未来的自己和用户的关系会从初识 → 熟悉 → 默契 → 知己逐步加深；常被想起的记忆会变强，长期没想起的会慢慢淡忘；每天最多整合一次，把最近的事提炼成持久记忆，并可能形成一条感悟。后台只管理这些开关，不查看任何单个用户的记忆内容。

没有配 LLM Key 时，整合只做规则处理（去重、遗忘、打卡里程碑、按规则刷新人格介绍），不会失败。
